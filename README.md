# 🌌 Minimalist Professional Portfolio — Soumik Chatterjee

A modern, clean, and minimalist developer portfolio built from scratch with React, styled using custom CSS and Tailwind utilities, and featuring rich interactive micro-animations.

🚀 **Live Link**: **[https://mcq-livid.vercel.app](https://mcq-livid.vercel.app)**  
🐙 **Repository**: **[https://github.com/soumik7484-art/port.git](https://github.com/soumik7484-art/port.git)**

---

## ✨ Features & Interactive Experience

### 1. 🤖 Resume-Trained AI Chatbot
- A custom AI chatbot widget located at the bottom right.
- It is trained on Soumik's actual resume data to answer specific questions about his **education, skills, projects, certifications, strengths**, and **contact information**.
- Includes fuzzy logic matching and quick reply chips. If asked off-topic questions, it politely redirects the user to ask about professional credentials.

### 2. 👋 Animated Welcome Greeting
- An animated vector-style greeting banner at the top of the hero section.
- Features a stylized custom SVG avatar waving its hand smoothly via CSS keyframe animations alongside a welcome bubble.

### 3. 🎯 Clean & Responsive Sections
- **Hero**: Clean name title, stats row, and floating profile card.
- **About**: Profile summaries and an information grid (Location, Education, Focus, Availability).
- **Skills**: Color-coded categorization (AI & Machine Learning, Frontend, Backend & Cloud).
- **Projects**: Clean cards featuring hover-lift effects, colored accent indicators, and direct GitHub links.
- **Resume**: Interactive card that lets visitors download `Soumik_Chatterjee_Resume.pdf` directly.

### 4. 🐱 Animated Social telemetry
- At the bottom of the page, three interactive SVG character nodes represent social contacts:
  - **GitHub Cat**: A cute cat robot holding a pulsing GitHub logo that wags its tail on hover.
  - **LinkedIn Suited Man**: A suited figure holding a LinkedIn badge whose tie wiggles on hover.
  - **Email Postman**: A delivery postman holding a glowing red envelope that floats on hover.

## 🚀 Running Locally

To clone the project and run it locally, use the following commands:

```bash
# Clone the repository
git clone https://github.com/soumik7484-art/port.git
cd port

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open **[http://localhost:5173](http://localhost:5173)** in your browser to view it.
